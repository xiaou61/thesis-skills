# Thesis Skill Optimization Variants

This directory contains three implementation-ready variants for improving the thesis-standardizer skill after GitHub research on thesis templates, academic writing skills, document linters, and rubric/checker workflows.

Use these files as review artifacts before choosing one implementation direction:

- `variant-1-hard-gates.md`: deterministic gates and low-risk checks.
- `variant-2-template-replication.md`: Word/template fidelity and school-format reproduction.
- `variant-3-agentic-scorer.md`: multi-agent pipeline, scoring, and optional intelligent verification.

Recommended acceptance path: implement Variant 2 as the main line, merge the deterministic gates from Variant 1, and keep Variant 3 as an optional advanced review layer.
